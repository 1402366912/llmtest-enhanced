LLM Test API Server

这是一个 API 服务器，前端已移除。

API 端点：

  • GET /api/config - 获取配置
  • PUT /api/config - 更新配置
  • GET /api/models - 获取模型列表
  • POST /api/models - 添加模型
  • PUT /api/models/:name - 更新模型
  • DELETE /api/models/:name - 删除模型
  • POST /api/test/start - 启动测试
  • POST /api/test/stop - 停止测试
  • GET /api/test/results - 获取测试结果
  • GET /api/ws - WebSocket 连接
